# Migrating to qmlqualitylens 0.5

Version 0.5 adds runtime coverage, benchmark regression, reachability, and GitLab Code Quality integrations. Artifacts and baselines use schema `0.5.0`; regenerate reviewed baselines after upgrading from 0.4.

## Reachability

Lens automatically treats `Main.qml`, `shell.qml`, and components rooted in `Window`/`ApplicationWindow` as entrypoints. Applications with other roots can configure project-relative paths and dynamic creation edges:

```json
{
  "entrypoints": ["src/AppRoot.qml"],
  "dynamic_component_edges": [
    { "from": "src/AppRoot.qml", "to": "src/pages/PluginPage.qml" }
  ]
}
```

Reachability follows ordinary resolved component uses, literal `Loader.source` QML files, simple `sourceComponent` references, and configured edges. When no entrypoint is known, cleanup falls back to incoming-reference evidence and marks reachability unavailable rather than declaring every component dead.

## Coverage

Configure a Cobertura report, such as one generated by Qoverage:

```json
{ "reports": { "coverage": "target/coverage.xml" } }
```

`coverage_evidence.json` reports file/line observations and maps them separately to declarative object creation lines, binding lines, and function/handler ranges. Partial report scope is visible. Coverage is scenario evidence and does not become a universal percentage gate.

## qmlbench

```json
{
  "reports": {
    "qmlbench": "target/qmlbench.json",
    "qmlbench_baseline": "benchmarks/linux-baseline.json"
  },
  "benchmark_policy": {
    "max_regression_percent": 5,
    "max_coefficient_of_variation": 0.05,
    "min_samples": 5
  }
}
```

Baseline comparisons require matching Qt, OS/QPA, OpenGL, window size, and benchmark names. Mismatched or noisy evidence is incomplete/warning evidence instead of a trusted regression result.

## GitLab Code Quality

Both `analyze` and `audit` accept `--format codeclimate`. Redirect the JSON array to a GitLab Code Quality artifact:

```sh
qmlqualitylens audit --config qmlqualitylens.config.json \
  --format codeclimate > gl-code-quality-report.json
```
